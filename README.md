# Résidanat 2027 · Constantine

Planning en 10 couches, suivi et annales 2020-2026, supports comparés, focus pomodoro, tableau blanc, cartes mentales, flashcards, simulations et profil — par Dr M.

- `index.html` : l'application
- `firebase-config.js` : ta configuration Firebase (laisse COLLE_ICI pour le mode local)
- `regles-firestore.txt` : règles avec liste d'emails autorisés (FIREBASE_OPEN = false)
- `regles-firestore-ouvert.txt` : règles avec inscription libre et gratuite (FIREBASE_OPEN = true)
- `manifest.webmanifest`, `sw.js`, icônes : installation comme application
